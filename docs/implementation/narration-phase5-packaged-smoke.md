# Phase 5 packaged Mac smoke — 11 October 2026

Scope: current M4 Pro Mac with previously installed Qwen CustomVoice and Base packs; this is a local PoC check, not a clean install or App Store qualification. The test used the disposable six-slide `Narration Video Acceptance` deck. No user deck was edited.

## Result

- `CI=true pnpm app:build` produced `SlopSlide.app` and `SlopSlide_0.1.0_aarch64.dmg`. `hdiutil verify` passed the DMG checksum. The app contains the speech and video executables and the speech-runtime license/notice files. The first DMG build attempt failed in the restricted terminal sandbox; the authorized native build passed.
- The generated app's linker-only ad-hoc signature **failed** `codesign --verify --deep --strict` (`code has no resources but signature indicates they must be present`). A disposable copy was re-signed locally with `codesign --force --deep --sign - --entitlements src-tauri/Entitlements.plist`; that copy passed strict verification. This does **not** provide Developer ID or App Store signing, notarization, or sandbox qualification. The generated DMG still contains the original unverified app. Use the locally signed copy only as this host's smoke artifact, not as a distributable installer.
- In the locally signed copy, a saved Ryan slide recording played. `Generate another take` synthesized with the bundled Qwen helper, increased slide 3's history from two to three recordings, and played the new take. After quitting and reopening the exact signed copy, Chat was the default sidebar tab, the deck still showed three takes, and the accepted recording played with advancing time.
- `Export → Narrated MP4` prepared the six-slide deck and saved `Narration Video Acceptance.mp4` into the disposable deck folder. Independent FFprobe inspection found **126.166667 s, 3,785 frames, 1920×1080 H.264 at 30 fps, and 24 kHz mono AAC**. The movie is 19,164,238 bytes. The app displayed the saved path. No system FFmpeg is used at runtime.
- Process-scoped `sandbox-exec` with `(deny network*)` synthesized 80,208 samples of 24 kHz WAV through the standalone connector and the **bundled** speech helper using the already installed stock model. The same network denial allowed the **bundled** video helper to encode a disposable copy of the app's frozen six-slide job. Its MP4 had the same duration, frame count, size and audio/video formats as the UI export. These checks prove offline reuse of installed models and local assets; they do not exercise first-run setup without network.

## Packaging and release handoff

The app bundle is about 18.5 MiB; its model packs are separate private app data (about 2.3 GiB each for CustomVoice and Base on this Mac). The `Info.plist` includes a microphone purpose string and the entitlements file requests audio input. The current ad-hoc build does not establish effective Store sandbox permissions. `Info.plist` advertises macOS 10.13 while narrated video requires macOS 12 or newer; align the advertised minimum and qualified features before distribution.

Before Matthias's final fresh-install check, produce an installer whose **contained** app passes strict signature verification with the intended distribution identity and entitlements, then verify the mounted DMG and test model download/import, microphone permission, deck-folder access, local synthesis, restart, and MP4 export on his Mac. Final license/notice aggregation and the Kleidi vendored-source provenance discrepancy remain open (see the runtime audit). App Store submission also needs whole-app agent/filesystem and sandbox review. Do not infer Store eligibility from this local PoC.

The native Save panel initially showed disabled Save/New Folder buttons during this smoke, including for HTML export. A later attempt in the locally signed copy enabled both controls and completed MP4 export; after restart the HTML panel also enabled them. The cause was not isolated, so repeat the save-dialog check during fresh-install acceptance.
