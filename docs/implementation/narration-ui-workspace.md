# Narration workspace cleanup

Implemented 11 October 2026 on `codex/narration-poc`, following the [chosen mockup](../mockups/narration-workflow-review.html).

The right sidebar has **Chat**, **Narration**, **Presentation presets** and **Files** tabs. Chat is selected when the app starts or a new workspace opens; switching tabs during a session preserves draft state. Clicking a slide thumbnail while viewing presets selects that slide and opens Narration. The left rail is the only slide navigation in this flow; while Narration or presets is selected, it labels slides as current audio, needing audio, or silent with their effective duration.

**Narration** owns scripts and audio. It shows counts for scripted visible slides and current accepted audio, offers **Draft blank slides…** and **Generate missing audio**, then shows the selected slide's script before its presenter, recording history and timing controls. Blank slides remain silent at five seconds by default. The blank-slide draft request targets only visible slide IDs whose current scripts are empty and explicitly instructs the agent to preserve every nonblank script. It uses the existing selected agent, tool permissions and review flow. Generation uses the existing whole-deck action, which reuses matching accepted takes. Earlier takes remain available in history.

**Presentation presets** owns the deck's speech provider, default presenter, language and pace. Local Qwen is shown as on-device; the provider selector stays disabled when it is the sole available provider. Selecting a different provider when one is actually connected does not silently replace an incompatible presenter: the panel asks for a compatible choice. Provider and presenter overrides remain possible for individual slides through the existing data model. The slide-level provider picker appears only when multiple providers are connected. Changing an inherited preset can make affected audio stale, but does not erase saved recordings or explicit slide settings.

**Preview deck** is directly available in the top toolbar regardless of the selected sidebar tab, using the existing narrated preview. **Export** remains a top-toolbar menu with narrated MP4, HTML and PNG options. These use the existing video preparation and export paths. The old duplicate preview and deck-default controls in Narration were removed.

The current `main` workspace model is integrated. A generated `deck.html` keeps `narration.json` and `audio/` beside the HTML file; an arbitrary HTML deck such as `talk.html` uses a sibling `talk.html.slopslide/` folder to keep its scripts and recordings separate from other decks. The narration MCP tools now require the workspace-relative HTML path. The existing workspace chat and Files tab remain available, and Preview Deck and Export appear in the top row while a deck is open.

Coverage: focused tests check the four tabs, Chat draft preservation, toolbar actions, slide-thumbnail routing and audio status, script/audio progress, blank-script drafting, inherited preset edits, incompatible-provider warning, slide override isolation and old recording access. `./check.sh` passes typecheck, build, formatting, clippy, 1,055 frontend tests and 429 Rust tests (5 ignored). A disposable native workspace smoke generated speech, played it, previewed the narrated deck and exported a 5.43-second 1080p H.264/AAC MP4. The macOS app and DMG bundle build completed. No new provider, cloud service or tone control is introduced. Distribution signing and Matthias's clean-install check remain Phase 5 work.
