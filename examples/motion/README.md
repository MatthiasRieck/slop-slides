# Motion study

Open deck.html in SlopSlide and present it. Four editable slide states demonstrate
a text reveal, a hero moving from right to left, and a larger hero composition.
Use Right/Space or click the right side; Left reverses the sequence.

The app injects its player. For a standalone browser demo, serve this repository and
open /examples/motion/preview.html. It loads the same runtime and styles.
Matching data-morph names connect elements on consecutive slides. Browsers without
View Transitions use the existing fade. Reduced motion disables morphing.
