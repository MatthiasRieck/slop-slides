# PowerPoint corner cases

Open `deck.html` in SlopSlide and export an editable PowerPoint to compare the
browser and presentation layouts. The type slide requests Google Fonts, with
system and local fallback stacks for offline rendering.

- **Type** covers tight line wraps, font fallback, tracking, alignment, and inline styles.
- **Rich text** covers lists, a table, explicit breaks, and gradient text.
- **Strokes** covers SVG dash lengths, cap styles, offsets, transforms, and markers.
- **Effects** covers CSS borders, shadows, rotation, transparency, cropping, and an
  editor-style arrow with a separate head path.
