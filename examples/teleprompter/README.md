# Teleprompter test deck

Open deck.html in SlopSlide, press Present, then N for the presenter view, and click the
scroll icon in its header. Each slide tests one thing; its speaker notes say what to try
(turn the teleprompter off to read them, as it shows the narration while it is on).

- title: reading word for word
- origin: scrolling, and a jump that skips paragraphs
- phases: paraphrasing
- repeat: the same phrase three times
- numbers: figures Whisper may write differently
- notes-only: no narration, so it follows the notes
- german: another language
- end: nothing to follow
