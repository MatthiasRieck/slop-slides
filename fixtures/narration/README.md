# Narration regression fixtures

These are the two retained inputs used by opt-in native tests:

- `b-native-bf16-ryan.wav`: generated stock-voice output used by the ten-minute video render/encode test in `src-tauri/src/video.rs`.
- `l-german-public-reference.wav`: public German reference used by the speech connector profile example. `german-public-reference.json` retains its CC0 source, transcript and provenance.

The [research summary](../../docs/narration.md) links to the original measurements and listening records. These fixtures are not bundled as selectable product voices.
